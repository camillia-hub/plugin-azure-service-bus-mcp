# Azure Service Bus MCP

Works with Azure Service Bus. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/azure-service-bus-mcp

Installs from the Camillia hub as `azure-service-bus-mcp-0f6c57`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
